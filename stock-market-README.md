## 📌 Overview

This project builds a data analysis platform that combines **predictive modelling** and **sentiment analysis** to forecast stock price movements and generate investment insights.

- ✅ Improved investment insight accuracy by **30%**
- ✅ Reduced manual analysis time by **50%**

---

## 🛠️ Tech Stack

| Tool | Purpose |
|---|---|
| Python | Core development |
| Pandas / NumPy | Data cleaning & manipulation |
| Scikit-learn | Predictive modelling (Random Forest, Regression) |
| NLTK / TextBlob | Sentiment analysis on financial news |
| Matplotlib / Seaborn | Data visualization |
| Jupyter Notebook | Analysis & reporting |

## 🚀 How to Run

```bash
# Clone the repo
git clone https://github.com/deeppatel5154/stock-market-predictive-analysis.git
cd stock-market-predictive-analysis

# Install dependencies
pip install -r requirements.txt

# Run the notebooks in order
jupyter notebook notebooks/
```
