### 📌 Featured Projects

#### 🏠 [Airbnb Review Sentiment Classification](https://github.com/deeppatel5154/airbnb-review-sentiment-classification)
*Graduate research project — end-to-end NLP pipeline on 13,000+ Airbnb reviews (Seattle Open Dataset)*
- Preprocessed 13,000+ raw reviews with tokenization, stemming, stop-word removal, and TF-IDF vectorization
- Addressed class imbalance in sentiment labels using SMOTE, improving minority-class recall
- Trained and hyperparameter-tuned Random Forest and LightGBM classifiers via Randomized Search CV, achieving **99.78%** and **99.59%** test accuracy respectively across positive/neutral/negative sentiment classes
- Applied n-gram analysis and keyword extraction to identify recurring themes (cleanliness, host interaction, location convenience)
- Performed K-Means and hierarchical clustering to segment reviews by underlying topic
- Collaborated with Kevin Patel and Janvi Patel using Git version control and shared code review
- **Stack:** Python, NLTK, Scikit-learn, Pandas, Seaborn
